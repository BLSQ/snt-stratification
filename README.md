# snt-stratification

SNT (malaria subnational tailoring) stratification on [OpenHEXA](https://openhexa.org) in one repo:
the data pipelines, the webapps (orchestrator, config editor) and the workspace bootstrap pipelines.

**Migration in progress.** This repo is being built as a clean snapshot of `BLSQ/snt_development`,
`BLSQ/snt_webapp_orchestrator`, `BLSQ/snt_workspace_bootstrap` and
`BLSQ/openhexa-webapps-edit-snt-config-json`. Until the import lands, the plan lives in
[`snt_development/docs/MIGRATION_PLAN.md`](https://github.com/BLSQ/snt_development/blob/main/docs/MIGRATION_PLAN.md).
Live country workspaces still run from those repos.
